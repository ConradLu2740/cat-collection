# 缅因猫

缅因猫是原产于美国缅因州的本土品种，也是世界上体型最大的家猫之一，成年公猫可达 7~11 公斤。它外表霸气如"小狮子"，性格却温柔憨厚，常被称为"温柔的巨人"。

## 巨型体型

- 生长周期长，**3~4 岁才完全长成**；幼年看似普通，成年后体积会明显超预期。
- 骨架宽大，公猫 7~11 公斤、母猫 5~8 公斤，肩部肌肉发达。
- 标志性特征：浓密的领圈毛、耳尖簇毛、厚实的大爪垫（便于在雪地行走）。
- 尾巴长而蓬松，几乎与身体等长。

| 部位 | 特点 |
| --- | --- |
| 被毛 | 半长毛、防水双层被毛，冬季厚夏季薄 |
| 头部 | 方形吻部，眼大而有神 |
| 眼睛 | 绿、金、铜色均可，随毛色而异 |

## 性格特点

- 温和、友善、包容，对人和动物都很耐心，适合多宠家庭。
- 不吵闹，叫声细软，更像"咕噜声"——想了解叫声差异可参考 [猫的叫声](/behavior/cat-vocalizations)。
- 聪明好奇，喜欢跟着主人走动，部分个体甚至愿意玩水。

## 毛发护理

- 双层被毛**容易打结**，建议每周梳 2~3 次；换毛季（春秋）几乎需要每天梳理。
- 使用针梳加排梳，重点照顾领圈、腋下、大腿根等易打结处。
- 大型猫对饮食和猫爬架承重要求更高，需提供结实稳固的设施。
- 个别缅因猫易患肥厚型心肌病（HCM）和髋关节发育不良，建议定期体检并关注繁育者的基因筛查记录。
