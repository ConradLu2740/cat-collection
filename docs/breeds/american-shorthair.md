# 美国短毛猫

![美短花纹特写](/images/american-shorthair.svg)

美国短毛猫是美国最受欢迎的品种之一，源自欧洲移民带来的工作猫，以**健壮体格和经典虎斑纹**著称。

## 外貌特征

- 经典**银色鱼骨纹（银虎斑）**是最具辨识度的花色，也有棕虎斑等
- 头圆脸宽，眼睛大而圆，绿色或金色
- 肌肉发达、体格结实，成年公猫 4-7 公斤

## 性格倾向

- **活泼好动、精力充沛**，喜欢玩耍和互动
- 聪明、训练性好，适合能陪玩的家庭
- 对家庭成员忠诚，适应力强

## 饲养要点

- 运动需求较高，建议准备**猫爬架、逗猫棒**与丰容玩具（规划中）
- 短毛被毛好打理，但换毛季仍需定期梳理
- 品种整体健康度较好，注意控制体重即可
