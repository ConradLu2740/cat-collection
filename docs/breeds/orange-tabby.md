# 橘猫

![橘猫的午后阳光](/images/orange-sunbath.svg)

橘猫不是独立品种，而是**毛色为橘色（姜黄色）的猫**的总称，常见于中华田园猫与各种短毛猫中。橘色基因与性别相关，**约 80% 的橘猫是公猫**。

## 外貌特征

- 毛色从浅杏色到深橘红，常带虎斑纹（经典斑/鱼骨斑）
- 白手套、白围脖等搭配常见
- 因基因原因，公猫占比极高

## 性格倾向

- 普遍**亲人黏人**，互动意愿强，有"大橘为重"的亲切昵称
- 食欲旺盛，需要注意控制食量（见[猫的饮食与营养](/care/diet-nutrition)）
- 好奇心强、适应力好，很适合新手

## 常见误区

- **"橘猫都胖"**：橘猫易胖更多是"能吃+容易得到溺爱"的结果，科学喂养一样能保持健康体重
- **"橘猫不是一个品种"**：是的，它是花色，不是纯种猫；田园橘猫体质普遍皮实
