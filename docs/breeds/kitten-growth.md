# 幼猫成长阶段

![奶瓶喂养幼猫](/images/kitten.svg)


从睁眼都费劲的小奶猫，到上蹿下跳的"拆家预备役"，幼猫的变化速度快得惊人。理解不同阶段的发育要点，能帮你更好地配合它成长，也更容易判断它是否健康。总体上幼猫的"猫生"大致可以划分为哺乳期、快速成长期和接近成年三个大阶段。

## 阶段总览

| 阶段 | 大致年龄 | 关键变化 |
| ---- | -------- | -------- |
| 新生儿期 | 0–2 周 | 闭眼、靠嗅觉找妈妈，几乎都在睡觉吃奶 |
| 过渡期 | 2–8 周 | 睁眼、学走路、断奶、社会化关键期 |
| 快速成长期 | 2–6 月 | 换牙、猛长个、精力爆棚 |
| 青春期 | 6–12 月 | 接近成年体型，性格基本定型 |

## 0–8 周：打好一生的底子

- 出生后约 7–14 天睁眼，3 周左右开始学走路
- 4 周起可以逐渐断奶，引入幼猫粮或羊奶粉
- **社会化黄金期**：多接触人、声音和其他猫，长大的猫会更亲人自信

## 2–6 月：飞速成长的"半大猫"

- 4–6 月换乳牙，注意检查是否有双排牙
- 正是打疫苗、驱虫和做绝育咨询的时间窗口
- 精力旺盛，需要充足的玩具和攀爬空间，否则家具就要遭殃

## 6–12 月：从少年走向成年

- 体型接近成年猫，食量趋于稳定
- 性格习惯基本定型，但仍保留玩耍天性
- 满 1 岁后可逐步换成猫粮（参见[新手养猫指南](/care/new-owner-guide)）
