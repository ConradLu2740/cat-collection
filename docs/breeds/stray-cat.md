# 流浪猫

![街角的路灯与流浪猫](/images/stray.svg)


流浪猫泛指没有固定主人、在户外自谋生路的猫，包括被遗弃的家猫及其后代。它们生活在小区、街头、校园和公园，既是一道熟悉的身影，也面临着疾病、饥饿和车辆等多重挑战。理解流浪猫的真实处境，是理性讨论"喂不喂、怎么帮"的前提。

## 流浪猫从哪里来

- 家猫走失或遭遗弃
- 未绝育的猫在户外繁殖，后代继续流浪
- 少数"社区猫"有人投喂，但严格意义上仍属无主猫

## 生存现状

- 户外平均寿命远低于家猫，主要威胁来自车祸、传染病和严寒酷暑
- 幼猫存活率低，流浪母猫可能一年繁殖两胎以上
- 过度繁殖又会引发扰民、传染风险等社区问题（见[幼猫成长阶段](/breeds/kitten-growth)）

## 人与流浪猫的关系

- 适度投喂能帮猫度过难关，但只喂不绝育会让数量持续膨胀
- 尊重邻居感受、定点定量投喂，是更可持续的共处方式
- 对亲人的猫，最好的帮助是引导它进入家庭

## TNR 与领养

- **TNR**（Trap-Neuter-Return，捕捉—绝育—放归）是目前公认的控制流浪猫数量、提升其生活质量的方式（见[TNR 科普](/adoption/tnr)）
- 愿意靠近人的流浪猫，经体检、驱虫、疫苗后常能成为很好的家猫
- 领养前请评估自己的时间与经济能力（见[领养指南](/adoption/adoption-guide)）
