# 布偶猫

![布偶猫的蓝眼睛](/images/ragdoll-blue-eyes.svg)

布偶猫是 20 世纪 60 年代在美国培育出的**大型长毛猫**，以温顺的性格和湛蓝的眼睛著称。

## 外貌特征

- 中长毛、丝质毛发，重点色（脸、耳、尾颜色深，身体浅）
- **蓝色眼睛**是品种硬标准
- 体型较大，成年公猫可达 6-9 公斤，成熟缓慢（3-4 岁才完全长成）

## 性格倾向

- 以**温顺黏人**闻名，被抱起时身体常放松下垂（"布偶"之名来源）
- 对人友善、容忍度高，适合家庭
- 相对安静，运动需求中等

## 饲养要点

- 长毛需要**定期梳毛**，否则易打结
- 肠胃相对敏感，注意逐步换粮
- 纯种猫常见健康关注点：肥厚型心肌病（HCM）、多囊肾病（PKD），选择正规繁育者时注意基因检测
