# 狸花猫

狸花猫是中华田园猫中最具代表性的类型，以黑灰相间的虎斑纹和强健体格著称。它聪明独立、捕鼠能力出众，是许多中国家庭"从祖辈就养过"的猫。

## 外貌特征

- 中等体型、肌肉结实，成年公猫约 4~6 公斤，比不少纯种猫更精瘦有力。
- 标志性**黑灰色鱼骨纹/斑点纹**，额头常有"M"形纹路，属于虎斑（tabby）的一种——可与 [橘猫](/breeds/orange-tabby)、[猫的毛色与花纹](/breeds/coat-colors) 对照了解。
- 头型圆润、大眼有神，眼色多为黄绿或琥珀色。
- 短毛为主，被毛硬挺有光泽，换季掉毛量不小。

## 性格特点

- 独立性强、有主见，会亲近人但不喜欢被强行抱。
- 聪明敏捷、学习能力强，很多狸花能学会开门、开抽屉。
- 领地意识强、捕猎欲高，适合有院子或能提供丰富互动的环境。
- 对主人忠诚，但社会化不足时容易对陌生人警惕。

## 常见误区

| 误区 | 事实 |
| --- | --- |
| "田园猫不用驱虫疫苗" | 与品种无关，室内外猫咪都需按时驱虫、免疫 |
| "土猫身体好不用绝育" | 不绝育的公猫会乱尿、母猫会闹猫，绝育更健康省心 |
| "狸花都凶" | 个体差异大，科学喂养加社会化可以非常黏人 |

狸花猫在血缘上与 [中华田园猫](/breeds/domestic-cat) 同源，只是虎斑纹更典型；"中国狸花猫"目前正逐步被部分国际协会认可，但国内多数狸花仍是普通家猫血统。
