# 暹罗猫

暹罗猫是源自泰国的古老品种，以修长的身材、宝蓝色的眼睛和标志性的重点色闻名。它性格外向黏人、话多好动，被称为"最像狗的猫"之一，适合喜欢高频互动、不介意"话痨"的家长。

## 外貌特征

| 特征 | 描述 |
| --- | --- |
| 体型 | 中等偏小、流线型修长，四肢细长，尾巴细而尖 |
| 被毛 | 短而贴身的丝质毛，**重点色**：脸、耳、四肢、尾巴深，身体浅 |
| 眼睛 | 鲜明的宝蓝色，杏仁形 |
| 头型 | 楔形头、大耳，现代系鼻梁笔直，传统系更圆润 |

重点色深浅受体温影响：幼猫出生时几乎全身浅色，随年龄增长和气温降低，深色区域会逐渐加深、扩大。

## 性格与叫声

- 极度**黏人**，喜欢参与主人的一切活动，长时间独处容易情绪低落或搞破坏。
- 聪明好奇，能学会开门、叼球等小把戏，需要丰富的互动玩具。
- 是公认的"话痨"品种，声音洪亮多变，会主动和主人"对话"——详见 [猫的叫声](/behavior/cat-vocalizations)。
- 对家人忠诚度高，但有时会"认人"，对陌生人保持警惕。

## 养护要点

- 短毛好打理，每周梳 1~2 次即可；重点色区域怕冷，冬季注意保暖。
- 精力旺盛，需要猫爬架、逗猫棒等垂直空间与互动，否则容易因无聊而捣乱。
- 纯种暹罗常见健康关注点：进行性视网膜萎缩（PRA）、肝脏淀粉样变性，选择正规繁育者并留意基因检测。
- 幼猫期多接触人和环境、做好社会化，成年后性格更稳定。
