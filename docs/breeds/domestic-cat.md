# 中华田园猫

中华田园猫指中国本土长期自然演化形成的家猫，**不是单一品种**，而是一个包含多种毛色与体型的"大家庭"。街头巷尾最常见到的猫大多属于田园猫。

## 常见花色类型

| 类型 | 特征 |
|---|---|
| 狸花猫 | 棕黑鱼骨纹，花纹清晰，气质机敏 |
| 橘猫 | 橘色/姜黄，多公猫，见[橘猫](/breeds/orange-tabby) |
| 奶牛猫 | 黑白相间，俗称"猫中哈士奇" |
| 黑猫/白猫 | 纯色系，各有拥护者 |
| 三花/玳瑁 | 母猫为主，花色独特 |

## 性格与体质

- 经过长期自然选择，**体质普遍皮实、适应力强**，被称为"中华体质"
- 性格差异极大：有黏人型也有高冷型，个体差异大于"品种标签"
- 聪明、生存能力强

## 领养意义

领养一只田园猫（见[流浪猫领养指南](/adoption/adoption-guide)）通常健康省心、性价比高，还能给流浪猫一个家。**"土猫"不是贬义词**——它们和任何纯种猫一样值得被好好对待。
