# 猫咪毛色大全

猫咪的毛色五花八门，橘、黑、白、狸花、三花、玳瑁、重点色……看似只是"好不好看"，背后其实是一套有趣的基因组合游戏。毛色主要由毛色基因、白色斑点和虎斑纹基因共同决定，同一种颜色在不同猫身上也会呈现千变万化的细节。

## 常见毛色一览

| 毛色 | 特点 | 常见搭配 |
| ---- | ---- | -------- |
| 橘色 | 姜黄到橘红，多为公猫 | 常带虎斑纹（见[橘猫](/breeds/orange-tabby)） |
| 黑色 | 纯黑或带暗纹，阳光下泛红褐色 | 乌黑油亮，也有"黑猫警长"形象 |
| 白色 | 通体纯白或大块白色斑 | 蓝眼白猫常伴听力问题 |
| 狸花 | 经典的鱼骨纹/斑点虎斑 | 中华田园猫的招牌花色 |
| 三花 | 黑、橘、白三色并存 | 几乎都是母猫 |
| 玳瑁 | 黑橘两色交杂，无白色 | 像龟壳的花纹，几乎都是母猫 |
| 重点色 | 身体浅、四肢耳尾深 | 暹罗、布偶的招牌（见[布偶猫](/breeds/ragdoll)） |

## 毛色背后的基因

- **性别与颜色**：三花、玳瑁的"黑+橘"组合需要两条 X 染色体，所以几乎都是母猫；橘色基因同样位于 X 染色体，导致约 80% 的橘猫是公猫
- **白色斑点基因**：能在任何底色的基础上"画"出白手套、白围脖，所以三花和玳瑁的本质区别只在于有没有白色
- **虎斑纹基因**：几乎所有猫都携带，纯色猫只是被"淡化"或"抑制"了花纹表达

## 关于花色的小误区

- 毛色**不等于品种**：田园猫里各种花色都能见到，纯种猫也并非只有一种颜色
- 毛色与性格**没有必然关系**："黑猫高冷""白猫文静"更多是刻板印象，个体差异远大于花色标签
