# 猫瘟（泛白细胞减少症）
> ⚠️ 本文仅供参考，不能替代兽医诊断。猫咪出现异常请及时就医。

猫瘟又称泛白细胞减少症（FPV），由猫细小病毒引起，是猫最凶险的传染病之一。它传染性极强、发病急、致死率高，但好在**核心疫苗能有效预防**，认识它是养猫人的必修课。

## 病因与传播

- 病原是**猫细小病毒**，与犬细小病毒同属但毒株不同。
- 主要通过**粪口途径**传播：病猫的粪便、呕吐物、唾液污染环境后，健康猫舔舐、接触即可能感染。
- 病毒**极其顽强**，在环境中可存活数月甚至一年，普通消毒剂难以杀灭，含氯消毒剂（如稀释后的次氯酸钠）更有效。
- 未接种疫苗的幼猫（尤其 2-6 月龄）是最高危群体。

## 典型症状

| 阶段 | 表现 |
|------|------|
| 早期 | 精神沉郁、食欲下降、发热（可达 40℃以上） |
| 中期 | 频繁呕吐、腹泻（严重时带血）、脱水 |
| 后期 | 白细胞骤降、贫血、休克，死亡率高 |

幼猫感染后可能表现为"突然死亡"而症状不明显，需高度警惕。

## 诊断与治疗

- 诊断：医生结合症状、血常规（**白细胞显著减少**是特征性指标）与抗原/核酸检测确认。
- 治疗原则：**住院支持治疗**为主——输液纠正脱水、止吐、抗感染防继发、补充营养。
- 目前**没有特效抗病毒药**，能否存活取决于就医速度和猫自身抵抗力；幼猫即使治愈也可能有后遗症。
- 家中若有其他猫，病猫须**严格隔离**，环境彻底消毒。

## 预防

- 按时接种**猫三联疫苗**（含 FPV 成分），幼猫首免后按医嘱补种，这是最可靠的防线。
- 新猫进家先隔离观察、确认免疫史，流浪猫需先完成接种再与原有猫接触。
- 多猫环境保持环境卫生，患病后痊愈的猫仍可能持续排毒一段时间。

## 常见问题（很多人问）

::: tip 很多人问
**Q：猫瘟治好了还会再得吗？**
A：痊愈后通常有较持久的免疫力，但仍建议按时接种疫苗巩固；康复期猫可能成为排毒者，家中新猫需谨慎。

**Q：打过疫苗的猫还会得猫瘟吗？**
A：疫苗大幅降低发病风险，但非 100%。免疫力低下、疫苗程序不全时仍可能感染，发现症状要尽快就医。
:::
