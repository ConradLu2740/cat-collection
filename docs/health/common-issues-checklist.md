# 猫常见健康问题自查清单

> ⚠️ 本文仅供参考，不能替代兽医诊断。猫咪出现异常请及时就医。

猫咪天生会隐藏不适，主人往往是发现异常的"第一道防线"。出现以下信号时，结合严重程度决定是否尽快就医。

## 常见症状速查

| 症状 | 可能原因 | 建议 |
|---|---|---|
| 呕吐 | 毛球、吃太快、食物不耐受、肠胃炎 | 偶发 1 次可观察；频繁/带血/精神差需就医 |
| 尿频、尿血、乱尿 | 尿路感染、膀胱炎、结石 | **尽快就医**，公猫尿闭是急症 |
| 食欲下降 | 应激、口腔问题、疾病早期 | 超过 24 小时不吃需就医 |
| 精神萎靡、躲藏 | 不适、疼痛、应激 | 结合其他症状判断，持续 1-2 天就医 |
| 打喷嚏、流涕、眼分泌物 | 上呼吸道感染（猫鼻支等） | 幼猫/体弱猫尽快就医 |
| 异常脱毛、皮肤红肿 | 皮肤病、寄生虫、过敏 | 就医或驱虫排查 |
| 呼吸急促、张口呼吸 | 呼吸道/心脏问题 | **急症，立即就医** |
| 牙龈红肿口臭 | 口炎、牙结石 | 口腔检查，必要时洁牙 |

## 判断要不要就医

- **紧急就医**：尿闭、呼吸困难、抽搐、大出血、误食有毒物、剧烈呕吐腹泻伴脱水
- **尽快就医**：超过 24 小时不进食、持续呕吐 2-3 次以上、精神明显变差
- **先观察**：偶发一次呕吐（吐毛球）、轻微打喷嚏但精神食欲正常——但观察期不超过 1-2 天

## 日常预防

- 保证饮水（[饮食与营养](/care/diet-nutrition)）、按时[疫苗与驱虫](/health/vaccination-deworming)
- 定期称重、观察排泄习惯变化
- 一年至少一次体检，老年猫半年一次
