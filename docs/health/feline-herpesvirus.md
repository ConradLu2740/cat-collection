# 猫鼻支（疱疹病毒）
> ⚠️ 本文仅供参考，不能替代兽医诊断。猫咪出现异常请及时就医。

猫鼻支由**猫疱疹病毒 1 型（FHV-1）**引起，是猫最常见的上呼吸道传染病之一，典型表现为打喷嚏、流眼泪、流鼻涕。它的一大特点是**一旦感染终生携带、容易复发**，治疗以缓解症状和加强护理为主。

## 传播方式

- 通过**飞沫和接触**传播：病猫打喷嚏的飞沫、眼鼻分泌物、共用的食盆水碗都可能传染。
- 多猫环境、猫舍、救助站是传播高发区；幼猫和免疫力低下的猫更易感、症状更重。
- 病毒在体外存活时间较短，但可借助潮湿环境短暂存活。

## 典型症状

| 部位 | 表现 |
|------|------|
| 眼睛 | 流泪、结膜充血、分泌物增多，严重时角膜溃疡 |
| 鼻子 | 打喷嚏、流鼻涕，鼻塞导致闻不到气味、食欲下降 |
| 口腔 | 部分猫出现口炎、流口水 |
| 全身 | 发热、精神差、食欲废绝 |

幼猫重症可能出现角膜穿孔或发展为肺炎，务必及时就医。

## 家庭护理

- **保证进食**：鼻塞时食物气味减弱，可加热食物增强香味，必要时医生指导下强饲。
- **清理分泌物**：用温湿棉片轻轻擦拭眼鼻分泌物，保持呼吸道通畅。
- **补充赖氨酸？**：赖氨酸补充对 FHV 的疗效存在争议，请遵医嘱，不要自行大量投喂。
- 病猫单独隔离，减少应激，环境保持通风和消毒。

## 复发与长期管理

- 病毒会**潜伏在神经节内**，猫在应激、换环境、生病或免疫力下降时可能复发，表现为周期性"感冒"。
- 日常重点是**减少应激**、营养均衡、按时接种疫苗（疫苗不能防感染，但能显著降低重症率）。
- 部分猫康复后可能遗留角膜疤痕或慢性鼻炎，需长期对症护理。

## 常见问题（很多人问）

::: tip 很多人问
**Q：猫鼻支治好了还会复发吗？**
A：疱疹病毒会终生潜伏在体内，应激（搬家、新猫、换粮）时可能复发。长期目标是减少应激、提高抵抗力，而非追求"彻底清除病毒"。

**Q：猫鼻支会传染给人吗？**
A：不会。猫疱疹病毒是猫科专属病原，不感染人。但猫之间传染性极强，多猫家庭需隔离病猫并消毒。
:::
