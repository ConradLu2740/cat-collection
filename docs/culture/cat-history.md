# 猫的历史

猫与人类的缘分，比想象中更长。从古埃及的神圣殿堂，到中世纪的海船与粮仓，再到今天互联网上刷不完的猫片，猫用几千年完成了从"抓老鼠的帮手"到"全家的主子"的身份跃迁。这段历史，其实也是人类生活变迁的一个缩影。

## 从野生到家养

- 家猫的祖先被认为是非洲野猫，最早与人类建立联系大约在近万年前的中东新月沃地
- 农耕兴起后，粮仓引来鼠患，野猫主动靠近人类聚居地"蹭饭"，彼此各取所需
- 与狗不同，猫更像是"自己选择"成为家猫的——这也是它们至今保留独立性的原因

## 古埃及与航海时代

- 古埃及人视猫为守护神之一，伤害猫甚至可能面临重罚，猫因此地位显赫
- 古埃及人还利用船运猫控制船上的鼠患，猫借此沿商路传播到地中海与欧洲各地
- 中世纪欧洲一度把黑猫与巫术联想在一起，猫的地位起伏不定，但粮仓和家庭始终离不开它

## 近代与互联网时代

- 18 世纪后，育种兴起，出现了布偶猫、英短等我们今天熟悉的家养品种
- 随着城市化，猫从"工具猫"逐渐变成纯粹的陪伴动物
- 互联网时代，猫视频、猫表情包让"云吸猫"成为全球现象，猫一跃成为数字文化的主角（更多趣闻见[猫的冷知识合集](/culture/cat-facts)）
