# 猫的冷知识合集

关于猫，总有一些让人"原来如此"的小知识。这里收集了十几条有趣又真实的冷知识，够你在撸猫时和猫友聊上一阵。

## 冷知识清单

1. **猫可以发出上百种声音**，而狗只有十几种——猫是"会说话"的动物
2. **猫的呼噜声并不总代表开心**，紧张或疼痛时它也可能呼噜，有研究认为这有助于自我修复
3. **猫每天睡眠可达 12–16 小时**，幼猫和老年猫睡得更久，但多为浅睡
4. **猫的嗅觉比人类强约 14 倍**，鼻子里有超过两亿个嗅觉感受器
5. **猫的舌头布满倒刺**，主要功能是梳理毛发、刮下肉屑，也让它喝水的姿势非常特别
6. **猫看不到正下方的鼻尖**，视力特点是擅长捕捉移动的小目标，对近距离静物反而不敏感
7. **猫的胡须是"测量尺"**，宽度和身体相当，用来判断自己能不能钻过缝隙
8. **猫耳朵可以独立旋转 180 度**，像一对微型雷达
9. **成年猫大多"乳糖不耐"**，喝牛奶容易拉肚子，补水应选清水或羊奶
10. **猫会"踩奶"**——小时候踩妈妈肚子催奶的动作，长大后只在放松时才会做（见[踩奶行为](/behavior/kneading)）
11. **猫的祖先来自沙漠**，所以普遍不喜欢水，也不太爱喝水
12. **猫的"咕噜"频率在 25–150 赫兹之间**，恰好落在有助于骨骼修复的声波区间
13. **三花猫和玳瑁猫几乎都是母猫**，因为黑橘配色需要两条 X 染色体
14. **猫能认出主人的声音**，只是心情不好时懒得回应罢了
