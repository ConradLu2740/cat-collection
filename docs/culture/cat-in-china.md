# 猫在中国文化中

中国人养猫的历史可以追溯到两千多年前。从"猫"这个字的源流，到古代文人雅士的"聘猫"仪式，再到今天遍布街头的猫咖和表情包，猫在中国文化里一直稳稳占据着一席之地。

## "猫"字的源流

- "猫"是形声字，从"犭"（犬旁），本义指捕鼠的动物；《说文解字》释为"狸属"
- 古人说"鼠善害苗，猫能捕鼠，故字从苗"，把"苗"与"猫"联系起来的说法在民间流传很广
- 猫还有一个古称"狸"，指代形似家猫的野猫，后来泛指猫类

## 古代养猫：从捕鼠到"聘猫"

- 最初养猫重在实用——守护粮仓、驱鼠护书
- 唐宋起养猫渐成风雅：想养猫要带"聘礼"上门求取，称为"聘猫"，仪式感十足
- 宋代城市里猫已经是很受欢迎的宠物，甚至出现为猫买鱼、置办"猫窝"的记录

## 民俗与故事

- 民间故事"狸猫换太子"让"狸猫"成为家喻户晓的意象
- 俗语里猫的典故很多：如"猫洗脸"被认为预兆天气、猫来富等说法在各地流传
- 传说猫有九条命，形容它生命力顽强、摔落也能平安

## 当代文化中的猫

- 养猫人数逐年攀升，猫咖、猫展、猫用品产业繁荣
- "云吸猫"、猫表情包与短视频让猫成为社交网络常客（更多趣闻见[猫的冷知识合集](/culture/cat-facts)）
