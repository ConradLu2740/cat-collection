# 领养前的心理准备

领养一只猫，意味着接下来十几年要对一个小生命负责。冲动领养是弃养和退养的重要原因。做好心理准备，比选猫粮、买猫窝更重要——它是你决定带猫回家之前，最先要做好的"功课"。

## 先问自己五个问题

1. 我能承诺照顾它 **10~15 年**吗？（搬家、换工作、结婚生子都不放弃）
2. 经济上能否承担：猫粮、猫砂、疫苗、绝育、日常体检和可能的高额医疗费？
3. 家庭成员（含室友）是否都同意，对猫毛或过敏是否有共识？
4. 每天能否保证陪伴和互动，出差时是否有人/机构代管？
5. 猫抓家具、半夜跑酷、偶尔乱尿，我能接受并想办法解决，而不是马上想"退"吗？

## 领养不是免费领东西

- 领养来的猫可能有**性格习惯差异**：有的胆小怕人，需要几个月的适应期。
- 流浪猫/救助猫常伴随**健康问题**：寄生虫、耳螨、应激，需要耐心治疗。
- 退养对猫是二次伤害：它会再次经历"被抛弃"的心理冲击。

## 心态调整建议

- 把预期设为"**先接受猫本来的样子**"，而不是"我要一只听话的完美宠物"。
- 初期多观察、少打扰：给猫一个安静角落，让它自己出来探索。
- 提前了解绝育、疫苗等安排，做好长期规划，具体流程可参考领养指南。
