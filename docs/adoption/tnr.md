# 流浪猫救助与 TNR

TNR 是 **Trap（诱捕）- Neuter（绝育）- Return（放归）** 的缩写，是目前公认的人道控制流浪猫数量的方法。

## 为什么是 TNR 而不是"抓走"

- 流浪猫数量增长的核心是**无序繁殖**；单纯捕杀/转移往往造成生态位空缺，新的猫群会填补
- TNR 通过绝育从源头控制增量，同时降低猫群打斗、发情嚎叫等社区矛盾
- 已绝育猫放归后仍能守住领地，减少新猫涌入

## TNR 操作流程

1. **观察记录**：记录猫群数量、喂食点、可接触程度
2. **诱捕**：使用专用诱捕笼（不要用手抓！），诱饵用香味食物
3. **送医绝育**：绝育 + 剪耳标记（公猫左耳、母猫右耳等社区惯例，便于识别）
4. **恢复放归**：术后恢复后放归原处，保持喂食点稳定

## 普通人如何参与

- **不随意投喂无计划**：如果投喂，建议配合 TNR，否则只是"让猫多生"
- **支持本地救助组织**：捐款、做诱捕志愿者、提供临时寄养
- **领养代替购买**：给可亲人的流浪猫找家，见[流浪猫领养指南](/adoption/adoption-guide)
