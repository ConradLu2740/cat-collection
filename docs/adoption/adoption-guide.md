# 流浪猫领养指南

领养一只流浪猫，等于给一只猫新的人生，也给自己一个长期的家人。本文覆盖从决定到适应的完整流程。

## 领养前先自问

- **能养 15 年左右吗？** 猫的寿命可达 15-20 年，中途不离不弃是底线
- **家人/室友支持吗？** 过敏、租房、同住人意见都要提前确认
- **预算够吗？** 猫粮、猫砂、疫苗、绝育、看病，月均数百到上千不等
- **有耐心吗？** 流浪猫可能胆小、有应激反应，适应期以周计

## 领养流程参考

1. **观察与选择**：先观察猫的性格（是否亲人、是否健康），不一定选最可爱的，选最适合你生活方式的
2. **健康检查**：带去体检，确认传染病阴性、寄生虫情况
3. **隔离适应**：到家先隔离在安静房间 3-7 天，与原住民猫逐步接触
4. **建立基础**：安排[疫苗与驱虫](/health/vaccination-deworming)、[绝育](/health/spay-neuter)

## 到家第一周要点

- **安全屋**：纸箱、猫窝 + 熟悉气味
- **不要强行抱**：用食物和逗猫棒建立好感
- **观察饮食排泄**：48 小时不吃不喝属紧张反应，超时就医
- **保持低刺激**：来访者减少、声音降低

## 流浪猫 vs 幼猫

- **成猫/流浪猫**：性格稳定、需求明确，适应后更省心；但需要更多耐心建立信任
- **幼猫**：社会化窗口期，好塑形但精力旺盛、破坏力强
