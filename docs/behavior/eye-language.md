# 猫的瞳孔语言

猫的瞳孔会根据光线和情绪变化，是判断猫咪**兴奋程度与意图**的重要线索。观察瞳孔需要先排除光线因素：强光下瞳孔自然缩小，黑暗中自然放大。

## 瞳孔状态解读

| 瞳孔状态 | 可能含义 |
|---|---|
| 正常圆瞳 | 放松，日常状态 |
| 细线状瞳孔 | 专注、准备捕猎、或受强光刺激 |
| 大而圆的瞳孔 | 兴奋、好奇、玩耍状态；也可能是恐惧 |
| 瞳孔放大 + 身体僵硬 | 警觉或恐惧，需要退让 |
| 缓慢眨眼 | 信任与放松，猫咪的"微笑" |

## 判断技巧

- **看光线**：同一种光线条件下对比最准确
- **瞳孔放大 + 耳朵前倾 + 尾巴摆动** → 玩耍/狩猎模式，可以陪玩
- **瞳孔放大 + 飞机耳 + 压低身体** → 恐惧，停止靠近

## 关于"缓慢眨眼"

缓慢眨眼是猫界公认的友善信号。你可以眯起眼睛慢慢眨回去，猫咪会逐渐信任你。这是建立关系最实用的技巧之一。
