# 猫咪抓挠与磨爪

抓挠是猫的**本能行为**，不是为了"报复"主人。理解它为什么抓、主动满足它的抓挠需求，比单纯阻止更有效——多数"乱抓家具"问题，本质是环境没有给猫提供更好的选择。

## 为什么猫要抓

- **磨爪**：抓挠能去掉旧指甲外鞘，保持爪子锋利。
- **做标记**：爪垫有气味腺，抓过的地方会留下气味与划痕，宣示领地。
- **伸展肌肉**：抓挠常伴随弓背伸懒腰，是全身拉伸的一部分。
- **释放压力**：兴奋、焦虑、无聊时都会用抓挠发泄情绪。

## 如何引导

1. **提供合格的抓板**：至少一个立柱式（可直立拉伸）加一个平面式，放在猫常抓的位置（沙发角、门口、睡觉处）。
2. **材质优先**：瓦楞纸、剑麻绳、粗糙木板都受欢迎，测试你家猫的偏好。
3. **正面强化**：在抓板附近奖励零食、陪玩，让"抓对地方"与好事绑定。
4. **禁止惩罚**：吼叫、喷水只会增加压力，可能让猫转向夜间更隐蔽地抓挠。

## 保护家具

| 策略 | 做法 |
| --- | --- |
| 物理遮挡 | 用双面胶、防抓贴覆盖沙发常抓区域，让触感不舒适 |
| 气味引导 | 在抓板撒少量猫薄荷或木天蓼，吸引猫使用 |
| 环境改造 | 靠墙放置猫爬架，让猫能在上面直立伸展 |
| 分散注意 | 多布置 [环境丰容](/care/enrichment)，运动量够了抓挠冲动自然下降 |
