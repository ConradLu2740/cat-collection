# 猫的行为语言

猫咪不会说话，但无时无刻不在通过**肢体语言**向你表达情绪与意图。学会观察尾巴、耳朵、瞳孔、胡须和姿态的组合信号，是理解猫的第一步。

## 观察原则

解读猫的行为语言时，**永远看整体，不看单点**：

- 一个信号（比如尾巴竖起）只有在与耳朵、瞳孔、身体姿态一起看时才有准确含义
- 每只猫有自己的性格与习惯，先观察你家猫的"基线状态"
- 环境变化（搬家、新猫、陌生人）会改变信号含义

## 主要信号系统

| 部位 | 表达重点 |
|---|---|
| [尾巴](/behavior/tail-language) | 情绪的最直观指示灯：竖尾、慢摆、炸尾含义各异 |
| [耳朵](/behavior/ear-language) | 警惕与放松：前倾、侧压、飞机耳 |
| [瞳孔](/behavior/eye-language) | 兴奋与攻击性：放大、收缩、缓慢眨眼 |
| 胡须 | 情绪与探测：前张、贴脸 |
| 身体姿态 | 弓背（防御）、露肚（信任）、贴地（紧张） |

## 常用互动信号

- **缓慢眨眼**：猫界的"飞吻"，表示信任与放松，可以回以同样的慢眨眼
- **露肚子**：表示信任，但不代表邀请摸肚（很多猫摸肚子会防御性咬人）
- **用头蹭你**：留下气味标记领地，同时表达亲昵
- **尾巴高高竖起、尖端轻弯**：猫咪心情愉悦的"打招呼"姿势
