# 猫的睡眠习性

猫是典型的"多阶段睡眠者"，一天要睡 12~16 小时，幼猫和老年猫甚至更多。但猫并不会一觉睡到天亮，而是分散在多个浅睡与深睡周期里，随时准备醒来活动。

## 为什么猫这么能睡

- **捕食者天性**：猫在野外属于伏击型猎手，能量消耗集中在短时爆发，其余时间用来保存体力。
- **昼夜节律**：猫是晨昏活跃动物（黄昏和清晨最精神），白天睡觉符合天性，不代表懒。
- **浅睡为主**：猫真正进入深睡的时间不长，浅睡时耳朵仍在转动，一有动静就能醒来。

## 常见睡姿与含义

| 睡姿 | 含义 |
|------|------|
| 蜷成一团、尾巴包脸 | 保暖+自我保护 |
| 四脚朝天露肚皮 | 极度信任、环境安全 |
| 半眯眼趴着 | 浅睡，随时可醒 |
| 贴着主人睡 | 把你当"安全的猫群成员" |

## 如何让猫睡得更安稳

- 提供**多个安静角落**：高处猫爬架、纸箱、软垫，让它自己选。
- 保持规律作息：固定喂食和玩耍时间，猫会跟着调整睡眠节奏。
- 睡前玩 10~15 分钟再喂一顿，容易引导它夜里安稳入睡。
- 如果猫夜里反复叫醒你，不要立刻回应"要饭"式要求，忽略一阵往往更有效。
