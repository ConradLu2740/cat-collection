# 踩奶

"踩奶"指猫咪用前爪在有弹性的表面（毛毯、抱枕、你的腿）上有节奏地一推一收。因为动作像揉面团，也常被称为"揉面团"。

## 为什么猫会踩奶

**踩奶源于幼猫哺乳期**：小猫吃奶时会用前爪反复踩压母猫乳房附近，刺激乳汁分泌。这一动作会与"温暖、饱足、安全"的体验绑定，成年后依然保留为放松行为。

## 踩奶时猫在想什么

- 感到**安全与满足**（重温幼年幸福记忆）
- 表达**信任**：踩奶通常只发生在它放心的地方
- 标记气味：爪垫有气味腺，踩踏也是在标记领地

## 主人怎么回应

- **不要打断**：踩奶是放松行为，打断反而增加压力
- 可以轻柔抚摸回应，猫咪通常会更放松
- 如果猫咪一边踩奶一边流口水或吮吸毛毯，说明它很投入，属正常现象
- 个别猫踩奶时会伸爪，若指甲划到人，勤剪指甲或垫一块厚毯子即可
