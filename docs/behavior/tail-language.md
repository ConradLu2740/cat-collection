# 猫的尾巴语言

尾巴是猫咪情绪最直观的"指示灯"。学会分辨常见的尾巴状态，能帮你快速判断猫咪当下的心情。

## 尾巴状态速查表

| 尾巴状态 | 含义 | 建议 |
|---|---|---|
| 高高竖起、尖端轻弯 | 心情好，打招呼 | 可以热情回应 |
| 竖直但紧绷、毛微微炸 | 兴奋/好奇，也可能紧张 | 观察其他信号再靠近 |
| 缓慢左右摆动 | 专注、观察中 | 不要打扰 |
| 快速抽动/甩动 | 烦躁、不耐烦 | 停止互动，给它空间 |
| 夹在两腿间 | 害怕、不安 | 降低刺激，提供躲避处 |
| 炸毛（变粗变蓬松） | 恐惧或防御 | 远离刺激源 |
| 尾尖轻颤 | 兴奋、期待（如等开饭） | 猫咪此时很开心 |

## 结合环境解读

尾巴信号需要结合场景：

- **看到你回家时竖尾** → 快乐迎接
- **玩耍中快速甩尾** → 狩猎本能被调动，可能突然扑咬
- **被陌生猫接近时炸尾** → 防御性极强，不要强行介入
- **尾巴贴着身体 + 躲藏** → 恐惧或生病，注意排查原因

## 尾巴受伤警示

猫咪的尾巴连接脊柱，**不要拉扯或踩踏**。如果发现尾巴下垂、无法抬起且伴随疼痛反应，可能是尾部神经损伤，应尽快就医。
