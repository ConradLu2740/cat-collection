# 猫的耳朵语言

猫的耳朵有 30 块以上的肌肉，可以灵活转动，是仅次于尾巴的情绪表达器官。

## 耳朵状态速查表

| 耳朵状态 | 含义 |
|---|---|
| 自然前倾 | 放松、好奇、对前方感兴趣 |
| 前后转动 | 在追踪声音，专注监听 |
| 侧压（飞机耳） | 紧张、防御、不悦，可能准备攻击 |
| 完全贴平向后 | 极度恐惧或服从 |
| 一只耳朵转向后方 | 分心，注意力在身后的声音上 |

## 耳朵 + 其他信号组合

- **飞机耳 + 瞳孔放大 + 尾巴快速甩动** → 攻击前兆，立刻停止互动
- **飞机耳 + 身体压低 + 尾巴夹紧** → 害怕，寻找躲避空间
- **耳朵前倾 + 缓慢眨眼** → 放松信任，可以继续温柔互动

## 耳朵健康小提醒

- 猫咪耳朵内侧应是**粉嫩干净**的；如果出现大量黑褐色分泌物、频繁甩头抓耳，可能是耳螨或感染，需要就医或驱虫检查
- 不要用棉签深入猫耳道清理，容易伤到耳膜
