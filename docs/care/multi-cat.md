# 多猫家庭相处

多只猫同住既有陪伴的乐趣，也考验资源与空间管理。大多数"打架"并非仇恨，而是**资源竞争和压力**的表现——科学引入新猫、公平分配资源，多数猫都能和平共处。

## 引入新猫的正确节奏

1. **隔离期**：新猫先在独立房间隔离 3~7 天，配好食物、猫砂盆和熟悉气味的用品。
2. **气味交换**：互换毯子、玩具，让双方先熟悉彼此气味，再隔门喂食。
3. **视觉接触**：短时间隔门缝或玻璃见面，观察反应，不强迫靠近。
4. **正式见面**：选双方放松的时段、有人监督，过程中多给零食奖励。
完整的接猫建议可参考 [领养指南](/adoption/adoption-guide)。

## 资源分配：数量要"N+1"

| 资源 | 最低数量建议 |
| --- | --- |
| 猫砂盆 | 猫数 + 1，分开放置（避免并排） |
| 食盆/水碗 | 每猫至少一套，摆放分散 |
| 休息点/窝 | 高处、隐蔽处各若干，保证每猫有"安全角落" |
| 抓板/玩具 | 多份轮换，减少争抢 |

猫砂盆位置尤其关键——详见 [猫砂盆与如厕训练](/care/litter-box)。

## 识别冲突与压力信号

- **哈气、炸毛、追逐**：明显冲突，先拉开，避免直接用手制止。
- **躲藏、食欲下降、过度理毛**：压力表现，检查资源是否被霸占。
- **真正的"猫斗"**：叫声凄厉、尾巴快速摆动、扭打带攻击——需要更长的重新引入流程。
- 抓挠标记突然增多也可能是领地压力信号，与 [猫咪抓挠与磨爪](/behavior/scratching) 相关。

## 相处锦囊

- 优先满足每只猫的**垂直空间**（猫爬架、高柜），让猫能"有路可退"。
- 喂食定时定点、弱势猫先吃，减少竞争。
- 多猫关系是动态的，偶尔小争执属正常；若持续攻击甚至见血，建议咨询专业行为顾问。
