# 新手养猫全指南

从决定养猫到把猫接回家，每一步都值得认真准备。本文覆盖接猫前的物品清单、环境布置与接猫后的适应期要点。

## 接猫前的物品清单

| 类别 | 必备物品 |
|---|---|
| 饮食 | 猫粮、食盆水盆（宽浅陶瓷/不锈钢更佳） |
| 如厕 | 猫砂盆（至少猫体长 1.5 倍）、猫砂、铲子 |
| 休息 | 猫窝/纸箱、猫抓板（必备，保护家具） |
| 安全 | 逗猫棒等互动玩具、指甲剪、航空箱/外出包 |
| 清洁 | 宠物专用梳子、洗耳液（备用） |

## 环境布置要点

1. **封窗**：猫咪没有恐高概念，开窗必须装防护网，这是安全底线
2. **隐藏危险**：收好电线、小物件、对猫有毒的植物（百合、绿萝等）
3. **设置"安全屋"**：到新家第一天给它一个安静小房间或纸箱，让它自己探索
4. **猫砂盆与食盆分开放**：猫咪不爱在吃饭地方如厕

## 接猫第一周

- **不要强行抱**：让猫主动靠近，蹲下、伸手背让它闻
- **观察饮食排泄**：前 24-48 小时不吃不喝属正常紧张反应，超过 48 小时需咨询兽医
- **逐步适应**：先固定一个房间，再慢慢开放全屋
- **建立规律**：固定时间喂食、铲屎、玩耍，帮助它建立安全感

## 首次就医安排

接猫后 1 周内建议做基础体检，确认年龄体重、寄生虫情况；按医嘱安排[疫苗与驱虫](/health/vaccination-deworming)，6 个月左右考虑[绝育](/health/spay-neuter)。
