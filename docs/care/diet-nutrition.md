# 猫的饮食与营养

猫是**专性肉食动物**，营养需求与狗和人差异很大。科学的饮食是猫咪健康的基础。

## 核心原则

1. **高蛋白为主**：猫需要充足的动物蛋白，牛磺酸是猫必需但自身难合成的氨基酸，缺乏会引发心脏与视力问题
2. **拒绝人类的"好心"**：洋葱、大蒜、巧克力、葡萄、酒精对猫有毒；餐桌剩饭盐分油脂过高
3. **水比粮更重要**：猫的渴感弱，建议多设饮水点、用流动饮水机，湿粮也是补水好方式

## 主粮选择

| 类型 | 优点 | 注意 |
|---|---|---|
| 干粮 | 方便、耐储存 | 注意含水量低，要保证饮水 |
| 湿粮/罐头 | 含水量高，补水好 | 开封后尽快食用，注意存储 |
| 生骨肉/自制 | 可控成分 | 门槛高，需严格营养配比，不建议新手直接尝试 |

## 喂食量参考

- 按猫粮包装上的建议量结合体重调整，**宁可少喂观察，不要一次喂多**
- 幼猫少食多餐（3-4 次/天），成猫可固定 2 次
- 保持体重稳定：摸肋骨应能轻易感觉到但看不到

## 常见误区

- **猫不能喝牛奶**：多数成年猫乳糖不耐受，会腹泻；宠物专用奶或水更合适
- **全素饮食不适合猫**：猫无法从植物中获取足够牛磺酸等营养
- **零食要克制**：零食占比不超过每日热量 10%
