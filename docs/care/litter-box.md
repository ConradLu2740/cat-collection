# 猫砂与如厕训练

大多数猫天生就会使用猫砂，你要做的是提供**合适、干净、安全**的如厕环境。乱尿乱拉通常不是"报复"，而是信号。

## 猫砂盆选择

- **尺寸**：至少是猫体长的 1.5 倍，宁大勿小
- **数量**：家中猫口数 +1 个猫砂盆（两只猫至少 3 个）
- **开放式 vs 封闭式**：开放式易散味但猫更安心；封闭式注意勤清理，有的猫会抗拒

## 猫砂选择要点

| 类型 | 特点 |
|---|---|
| 膨润土砂 | 结团好、猫脚感接近自然土 |
| 豆腐砂/植物砂 | 可冲厕所（少量）、粉尘低 |
| 水晶砂 | 吸味强但脚感硬，部分猫不接受 |

## 如厕训练小技巧

1. 新猫到家，先带它到猫砂盆前，扒两下示意
2. 猫砂盆放在**安静、少打扰**的角落，避开食盆水盆
3. 每天至少铲 1 次，砂盆每周彻底换洗
4. 错误发生后**不要打骂**：清理干净、去除气味，检查环境因素

## 乱尿排查清单

如果猫突然乱尿，按顺序排查：

1. **健康问题**（最常见）：尿路感染、膀胱炎、肾病——先就医
2. 猫砂盆太脏 / 换砂太频繁 / 换了不喜欢的砂
3. 位置变动、家里来了新成员、环境压力
4. 未绝育公猫的标记行为 → 考虑[绝育](/health/spay-neuter)
