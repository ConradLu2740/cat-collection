# 猫的日常护理

日常护理不只是"让猫变好看"，更是发现健康问题、增进感情的机会。梳毛、剪指甲、洗澡、清洁耳朵四件事掌握好，大部分猫咪都能配合得很好。

## 梳毛

- 短毛猫每周 1~2 次，长毛猫每天或隔天一次。
- 选对工具：长毛用针梳+排梳，短毛用橡胶刷或硅胶梳。
- 从背部开始顺着毛向梳，肚子和腿根要轻柔。
- 梳毛能减少毛球、提前发现皮肤问题（红肿、跳蚤、异常掉毛）。

## 剪指甲

- 每 2~4 周剪一次，用猫专用指甲剪。
- 只剪**尖端透明部分**，避开粉红色的血线；剪到血线会痛还会出血。
- 不配合时先做脱敏：每天揉揉爪垫、给零食奖励。
- 剪完立刻给奖励，让它把"剪指甲"和好事联系起来。

## 洗澡

- 猫不需要频繁洗澡，健康家猫几个月一次即可；洗太勤反而伤皮肤。
- 用猫专用浴液，水温 38℃ 左右，别洗头（用湿毛巾擦脸即可）。
- 洗后尽快吹干，注意防应激；实在怕水的猫可改用宠物湿巾局部清洁。

## 耳朵清洁

- 健康的猫耳道应是干净的浅粉色；发现黑褐色分泌物、频繁甩头抓耳，先怀疑耳螨。
- 用宠物洗耳液滴入耳道，轻揉耳根后让猫自己甩出，再用棉球擦拭外耳。
- **不要用棉签掏耳道深处**，容易把污垢推进去甚至伤到鼓膜。
