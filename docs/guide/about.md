# 关于猫咪知识库

**猫咪知识库**是一个由 Conrad 个人维护的中文猫知识 wiki，从「猫咪收藏馆」演化而来。

## 为什么做这个站

最初它只是一个收集猫图和猫文的个人收藏站。收藏的过程中发现：好内容散落各处，读完就忘，想查的时候找不到。于是决定把它改造成一个**结构化的知识库**——把收藏的内容消化成自己的话，按主题整理成词条，方便自己和同好随时查阅。

## 内容从哪里来

- 个人养猫经验与观察
- 公开科普资料（参考后原创改写，标注来源）
- 猫友社区的经验交流

## 使用与贡献

- 词条全部开源在 [GitHub](https://github.com/ConradLu2740/cat-collection)，欢迎提 Issue 纠错或补充
- 内容组织遵循[内容体系规范](/guide/content-guide)
