## 1. 站点定位

- **受众**：中文养猫人 / 猫爱好者，从新手到进阶
- **差异化**：不搬运维基/百度百科；用原创语言 + 实操经验，做「实用、可查、有温度」的知识库
- **内容原则**：一事一词条；事实注明来源；医疗类内容加免责声明；图片为图库子栏目

## 3. 词条模板规范

每个词条是一个 Markdown 文件，**frontmatter + 正文**结构：

```yaml
---
title: 词条名称          # 必填，页面标题
aliases: [别名1, 别名2]  # 可选，别名/重定向词
category: 行为与沟通      # 必填，一级分类
tags: [肢体语言, 情绪]    # 必填，2-5 个标签
updated: 2026-08-10      # 必填，最后更新日期
sources:                 # 引用清单
  - site: 来源平台
    title: 原文标题
    author: 作者（可选）
    date: 发布日期（可选）
    url: 原文链接
---
```

正文固定区块顺序：

1. **摘要 lead**（2-3 句，一句话说清这个词条讲什么）
2. **正文分节**（`##` 分节，可含表格/列表/图片；第 1 个分节通常为「概述」）
3. **相关词条**（`## 相关词条`，`- [词条名](/path/to/entry)` 双向互链）
4. **参考资料**（`## 参考资料`，列出 sources）
5. **免责声明**（仅健康/医疗类）：`> ⚠️ 本文仅供参考，不能替代兽医诊断。猫咪出现异常请及时就医。`

## 5. 内容质量规则

1. **原创改写**：不直接复制百科/外站正文；可参考后用自己的话重写，引用处标注来源
2. **链接规范**：sources 必须给到具体文章页 URL（不是站点首页），保留获取日期
3. **医疗免责**：health/ 下所有词条顶部或底部加免责声明
4. **互链**：每个词条至少 1 个「相关词条」链接，形成知识网络
5. **更新机制**：每半年 review 医疗/领养类时效内容（可用自动化任务提醒）
