# 新手学习路径

猫咪知识库有 40+ 个词条，不知道从哪里读起？下面三条路径帮你按需取用——每条都是按"从零到进阶"排好的阅读顺序。

## 🐾 路径一：新手养猫（从接猫到安稳生活）

适合准备养猫 / 刚接猫回家的你。

1. [领养前的心理准备](/adoption/mindset) —— 先想清楚"我能养好一只猫吗"
2. [流浪猫领养指南](/adoption/adoption-guide) 或 [新手养猫全指南](/care/new-owner-guide) —— 接猫流程与物品清单
3. [幼猫成长阶段](/breeds/kitten-growth) —— 了解不同月龄的小猫需要什么
4. [猫的饮食与营养](/care/diet-nutrition) —— 吃对了，健康就赢了一半
5. [猫砂与如厕训练](/care/litter-box) —— 解决"乱拉乱尿"的第一课
6. [猫的日常护理](/care/grooming) —— 梳毛、剪指甲、洗澡基本功
7. [疫苗与驱虫](/health/vaccination-deworming) + [绝育](/health/spay-neuter) —— 打好健康地基

**进阶**：[猫的行为语言](/behavior/cat-body-language) → [多猫家庭相处](/care/multi-cat) → [老年猫护理](/care/senior-cat)

## 🏥 路径二：猫生病怎么办（识别 → 判断 → 处理）

适合发现猫咪出现异常的当下。

1. [常见健康问题自查清单](/health/common-issues-checklist) —— 先对照症状判断严重程度
2. [猫的常见传染病](/health/infectious-diseases) —— 认识四大传染病
3. [猫瘟详解](/health/feline-panleukopenia) / [猫鼻支详解](/health/feline-herpesvirus) / [猫传染性腹膜炎 FIP](/health/fip) —— 重点疾病逐一了解
4. [猫泌尿系统疾病](/health/urinary-disease) —— ⚠️ 公猫尿闭是急症，先看这篇
5. [猫皮肤病](/health/skin-disease) —— 猫癣、耳螨、跳蚤识别与处理

> ⚠️ 词条内容仅供参考，不能替代兽医诊断。出现异常请及时就医。

## 🐈 路径三：品种挑选（认识不同猫咪）

适合想了解品种差异、准备选猫的你。

1. [中华田园猫](/breeds/domestic-cat) —— 本土猫的"大家庭"
2. [猫咪毛色大全](/breeds/coat-colors) —— 先看懂颜色再说品种
3. 热门品种逐个看：[橘猫](/breeds/orange-tabby) · [狸花猫](/breeds/lihua-cat) · [英短](/breeds/british-shorthair) · [美短](/breeds/american-shorthair) · [布偶猫](/breeds/ragdoll) · [暹罗猫](/breeds/siamese) · [缅因猫](/breeds/maine-coon)
4. [流浪猫](/breeds/stray-cat) —— 领养之前，先了解它们

**如果只看一篇**：[中华田园猫](/breeds/domestic-cat)（田园猫体质皮实、性格各异，是领养首选）

## 三句话总结

- **新手** → 从"心理准备"开始，按路径一走一遍
- **生病** → 先查[自查清单](/health/common-issues-checklist)，分秒必争时优先看[泌尿系统](/health/urinary-disease)
- **选猫** → 先看[毛色大全](/breeds/coat-colors)，再按品种逐个了解
